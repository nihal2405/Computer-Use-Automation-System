# Evidence collection

No actual runs have been performed. This directory contains an evidence plan,
not sample results. Add files only after real execution and redaction review.

- `example_capability.json`: the validated, parameterized artifact generated by
  a successful live LLM discovery run.
- `discovery/`: structured events and result from that run, identifying model,
  target/version, run ID, actions, concise decision reasons, and checkpoints.
- `replay_success/`: events and result for the saved artifact using a different
  synthetic member ID, with model access disabled.
- `replay_not_found/`: events and a structured known business outcome.
- `human_handoff/`: continuous run events, intervention request, captured human
  action metadata, sanitized failure evidence, and resume/completion result.

Correlate each run with artifact version, target configuration, and source commit.
Store raw development output only in ignored runtime directories. Never commit
API keys, browser authentication state, credentials, full PII, or raw sensitive
financial information. Do not relabel fixtures or hand-authored steps as discovery.
